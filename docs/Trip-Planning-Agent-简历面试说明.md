# Trip Planning Agent 简历面试说明

这份文档用于两类场景：

- 把项目写进简历时，直接摘取项目描述和亮点
- 面试讲项目时，快速组织 30 秒、1 分钟和深入版表达

## 项目一句话

独立设计并实现 AI 旅行规划工作台，基于 `Vue 3 + TypeScript + FastAPI + OpenAI-compatible API + 高德地图能力` 生成结构化多日行程，并支持 Trip Workspace、固定预约、局部重规划、出发前预检、地图可视化和 `.ics` 日历导出。

## 简历精简版

独立设计并持续迭代 AI 旅行规划工作台，构建“行程生成 -> 工作区保存 -> 预约约束 -> 局部修复 -> 预检刷新 -> 日历导出”的完整链路。  
基于多阶段编排整合 LLM 规划能力与地图事实数据，支持结构化行程生成、Trip Workspace 持续编辑、固定预约覆盖诊断和出发前预检，提升结果的可执行性和工程可控性。

## 简历详细版

### 项目名称

Trip Planning Agent / AI 智能旅游助手

### 技术栈

- 前端：`Vue 3`、`TypeScript`、`Vite`
- 后端：`FastAPI`、`Pydantic v2`、`pytest`
- 模型层：`OpenAI-compatible API`
- 地图层：高德 `JS SDK`、高德 `MCP`、高德 `Web Service fallback`
- 工程化：`Docker Compose`、前端构建校验、后端回归测试

### 项目定位

项目不是“让模型输出一段旅游文案”，而是面向真实出行场景输出可执行、可编辑、可重规划的结构化行程系统。  
用户不仅能生成结果，还能把结果保存成工作区，继续补充备注、录入固定预约、锁定部分日期、刷新出发前预检，并导出到日历工具。

### 个人职责

- 负责前后端整体架构设计、主链路实现与持续重构
- 设计多阶段编排链路，拆分 seed itinerary、事实补全、路线生成、后处理和诊断收口
- 设计并实现 `Trip Workspace`，支持请求快照、结果快照、分享访问和持续编辑
- 设计并实现固定预约链路，覆盖预约录入、校验、请求注入、覆盖诊断和保底锚定
- 设计并实现工作区重规划，支持整程重规划、单日重规划和 `fill_gaps` 缺口修复
- 设计并实现出发前预检刷新链路，支持天气、路线、营业时间、预约覆盖等检查项

### 关键成果

- 打通“生成 -> 补事实 -> 保存工作区 -> 继续编辑 -> 重规划 -> 预检 -> 导出”的完整链路
- 实现结构化 `Trip Workspace` 持久化，支持草稿、结果快照、分享链接和锁定日期
- 实现固定预约能力，支持酒店、航班、火车、餐厅、门票等结构化预约录入
- 实现 `reservation_coverage` 诊断，区分 `covered / unresolved / pending`
- 实现预约保底锚定，降低真实预约未落到日程中的风险
- 实现缺口驱动的单日补齐，覆盖早餐、午餐、晚餐、加餐、活动、住宿、预约和整天日程
- 实现工作区最近一次重规划摘要 `last_replan_summary`
- 实现工作区出发前预检刷新与最近一次预检摘要 `last_precheck_summary`
- 实现 `.ics` 导出，支持将工作区中的预约、住宿和显式活动写入日历文件

## 30 秒介绍

我做的是一个 AI 旅行规划工作台。用户输入目的地、日期、预算和兴趣后，系统会先生成一个结构化的多日行程骨架，再结合地图能力补齐景点、餐饮、酒店、天气和路线信息，最后把结果保存成可持续编辑的 `Trip Workspace`。  
用户后续还能录入固定预约、锁定部分日期、局部重规划、刷新出发前预检，并导出 `.ics` 日历文件。

## 1 分钟介绍

这个项目是一个面向真实出行场景的 AI 旅行规划系统。整体技术栈是 `Vue 3 + TypeScript + FastAPI`。我没有把它做成一次性文案生成，而是做成结构化、可持续编辑的工作区产品。  
核心链路是：先由 LLM 生成初步行程骨架，再通过地图能力补齐景点、餐饮、酒店、天气和路线等事实数据，最后汇总成结构化 itinerary。生成结果会持久化成 `Trip Workspace`，用户可以继续补充备注、录入固定预约、锁定部分日期，并基于冲突或缺口做局部修复。  
我重点做了三类能力：一是多阶段 AI 编排和结构化校验，二是工作区与预约约束链路，三是预检刷新、日历导出和整体工程化落地。

## 面试时建议重点讲的三点

- 不只是“调用模型出文案”，而是把 AI 规划、地图事实和规则校验接成了可控链路
- `Trip Workspace` 让生成结果从一次性输出变成可持续编辑的产品状态
- 预约注入、覆盖诊断、局部修复和预检刷新让结果更接近真实可执行行程
